I build practical open-source software around agent interfaces, privacy, automation, and native experiences. I care about clear boundaries, useful defaults, and tools people can inspect and run themselves.

- ⚡ [**ocgo**](https://github.com/ElZaWarudo/ocgo) — use an OpenCode Go subscription from Claude Code or Codex CLI through a local compatibility proxy.
- ⚔️ [**KRT**](https://github.com/ElZaWarudo/KRT) — portable agent skills for requirements, delivery orchestration, repo health, and release hygiene.

### Local-First Apps

- 🎬 [**Unilink**](https://github.com/ElZaWarudo/unilink) — a Tauri tray app that brings Stremio playback, subtitles, and episode queues to a second screen on your local network.
- ☕ [**Tinto**](https://github.com/ElZaWarudo/tinto) — a read-only desktop monitor for local Git repositories while coding agents edit them.

## What I'm Building
